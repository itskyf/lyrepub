# Source characterization

Characterization of the two selected EPUB sources and the Đêm hội Long Trì
audiobook, covering only properties that can materially affect the evaluated
pathways (TTS synthesis for Thăng Long nổi giận, alignment of the existing
audiobook for Đêm hội Long Trì). Source observations, not a difficulty
ranking; the six text strata organize the survey and imply no ordering.

Evidence types used below, defined once:

- **Observed source property** — direct deterministic inspection (block
  text, OPF/NCX structure, ffprobe metadata, regex-countable features).
- **Automated candidate evidence** — output of NER, language detection, or
  segmentation models; used to find cases, never as reference annotations.
- **Manual judgement** — human listening or focused reading of a specific
  case, recorded with what was observed and where.

## Scope and reproduction

Silver artifacts are gitignored and regenerated by these commands (run from
the repository root; bronze sources fetched via
`scripts/fetch_release_sources.sh`):

| Artifact (data/silver/) | Command |
| --- | --- |
| `epub_structure.txt` | `pixi run --environment dev python scripts/inspect_epub_structure.py` |
| `blocks.csv`, `scan_summary.txt` | `pixi run --environment dev python scripts/scan_sources.py` |
| `blocks_enriched.csv`, `ner_report.txt` | `PYTHONPATH=src pixi run --environment dev uv run --script scripts/screen_ner.py` |
| `language_mixing_report.txt` | `PYTHONPATH=src pixi run --environment dev uv run --script scripts/screen_language_mixing.py` |
| `*.ffprobe.json`, `audiobook_tracks.csv`, `audiobook_report.txt` | `./scripts/inspect_audiobook.sh` then `pixi run --environment dev python scripts/inspect_audiobook.py` |

Key tool versions: fast-ebook 0.2.0, lingua-language-detector 2.2.0,
ffprobe 9.0.2; the selected NER and SaT checkpoints and their revisions
are pinned in their committed source modules (`src/lyrepub/ner.py`,
`src/lyrepub/segmentation.py`).

## EPUB structure

### Thăng Long nổi giận (ISBN 9786045633946)

Observed (`epub_structure.txt`): 26 XHTML documents, one per chapter; spine
order `C1..C26` matches the NCX navMap ("Chương 1..26") one-to-one; all
spine entries are effectively linear. Dublin Core: title/creator/language
`vi`, date 2016-06-18; `dc:identifier` is a UUID (`urn:uuid:e5cb99bd-…`),
not the ISBN. The cover is a manifest image with no cover document; no
front/back matter documents. 3,033 extracted text blocks.

Processing-relevant: clean 1:1 chapter structure; no non-linear or
ToC-absent content; source identification cannot rely on `dc:identifier`
(both books use producer UUIDs; the ISBN directory keys are the stable
identifiers).

### Đêm hội Long Trì (ISBN 9786326186253)

Observed (`epub_structure.txt`): 11 spine documents, all effectively
linear: `cover.xhtml` (s0), `section_11` (s1), `section_2..9` (s2–s9),
`section_12` (s10). The navMap has 8 entries — LỜI NÓI ĐẦU (s2) and
sections I–VII (s3–s9) — and does not cover s0, s1, or s10. Dublin Core:
publisher `dtv-ebook.com`, date 2017-04-03, calibre UUID identifier.

Direct content inspection of the three ToC-absent documents: s0 is an
SVG-wrapped cover image (0 text blocks); s1 is a 25-block author biography
("Nhà văn NGUYỄN HUY TƯỞNG (1912 – 1960)…", 803 chars) — narratable text
that sits in reading order between the cover and LỜI NÓI ĐẦU with no
navigation entry; s10 is a single full-page image with no text. 1,535
extracted text blocks.

Processing-relevant: any reading-order-derived target (TTS or alignment)
must include s1 even though no ToC entry reaches it; s0/s10 contribute no
text.

## Text strata

Per-block distributions below are observed regex-countable features from
`scan_summary.txt`; locations are `spine_index href #block_index`.

### Ordinary text

Book 1: 3,033 blocks, char length median 145, p90 589, p99 1512, max 3427.
Book 2: 1,535 blocks, median 67, p90 282, p99 732, max 1741 — shorter,
dialogue-shaped blocks. Dialogue-marker blocks
(starting "- ") are 1,137 (37%) in book 1 and 787 (51%) in book 2. Sentence
lengths (SaT segmentation): median 64/max 452 (book 1) and
median 42/max 500 (book 2). No control/format/private-use/replacement
characters, non-Latin letters, or unusual symbols were found in either
book (Unicode/source quality inventory, `scan_summary.txt`).

### Number and date expressions

Book 1: 149 digit runs in 93 blocks, 59 year-like values, 6 date-like
values; the digit-bearing blocks include parenthetical historical notes,
e.g.
`9786045633946 s2 Text/3.html #26 — "… (Năm 1274 nhà Nguyên tập Kinh Hồ đẳng xứ hành trung thư tỉnh. Năm 1277 gộp Ngạc Châu (Hồ Bắc) vào Đà…"`
(nested parens, Western years, Sino-Vietnamese place names). Book 2 is
number-sparse: 28 digit runs, 6 year-like, 0 date-like (e.g.
`9786326186253 s1 Text/section_11.html #2 — "(1912 – 1960)"`).

### Named entities

Automated annotation (NlpHUST/ner-vietnamese-electra-base; candidate
evidence, not reference labels): book 1 — 4,613 PER, 1,928 LOC,
44 ORG, 637 MISC; book 2 — 1,314 PER, 121 LOC, 6 ORG, 55 MISC
(`ner_report.txt`). The ORG channel is sparse in both books (recorded
limitation of the checkpoint). Inspected examples from the frozen
entity-rich cases include
`9786045633946 s2 Text/3.html #26` (dense historical names/years) and
`9786326186253 s1 Text/section_11.html #3 — "Quê quán: Dục Tú, Đông Anh, Hà Nội"`.

### Long text

Book 1: p99 1,512, max 3,427 chars; the longest block is
`9786045633946 s5 Text/6.html #9 — "Phủ Chiêu Quốc không phải là phủ lớn nhất…"`
(3,427 chars). Book 2: p99 732, max 1,741; its longest block is
`9786326186253 s5 Text/section_5.html #132`.

### Code-switched and mixed-language text

The mixed-language screen (`language_mixing_report.txt`; lingua 2.2.0
`detect_multiple_languages_of` over all 4,568 blocks, 263 flagged) is
automated candidate evidence, not a reference annotation: the detector's
experimental span mode is dominated by noise on this corpus — tiny
non-Vietnamese spans on ordinary Vietnamese text (e.g. "An Nam" repeatedly
labeled Zulu; short play dialogue labeled Tagalog/Sotho/Ganda in book 2).
Manual judgement (every non-Vietnamese span in the flagged blocks was
read) confirmed:

- One confirmed foreign-language phrase, in book 1: the French title in
  `9786045633946 s12 Text/13.html #30 — "… Cuốn du ký (Le Livre de Marco Polo)…"`.
- Book 1 also contains several parenthetical original-form foreign proper
  names — `(Koubilay)` in the same block, `(Tagai-sariq)` in
  `s18 Text/19.html #35`, `(Aric Khaya)` in `s19 Text/20.html #64`,
  `(Mangqudai)` in `s20 Text/21.html #191` — and foreign proper names in
  Vietnamese sentences ("Marco Polo" as sentence subject in
  `s12 Text/13.html #37`); these are proper names, handled primarily under
  Named entities, not code-switching.
- Book 2: no mixed-language example was confirmed among the flagged
  candidates; the flagged spans read as plain Vietnamese dialogue or
  headings.

### Punctuation-related structures

The two books use opposite quotation conventions (observed): book 1 has 841
straight double quotes in 356 blocks vs 40 curly; book 2 has 0 straight vs
39 curly. Neither book contains an em dash; the ellipsis character is rare
(13 and 6). Other observed punctuation: book 1 — 500 question marks, 225
exclamations, 120 semicolons, 222 parentheses; book 2 — 325 questions
(1.75/1k chars), 154 exclamations, 555 colons (2.99/1k). Notable
structures:

- Mixed straight and curly quotes within one block:
  `9786045633946 s12 Text/13.html #68 — "Thu thập tin tức xong, Đỗ Vỹ bèn cho người gửi một phong thư dán kín…"`
  (3 curly + 9 straight in one block).
- Slash-enumerated list with digits inside a parenthetical:
  `9786045633946 s2 Text/3.html #70 — "(Văn Thù: là một trong 8 vị đại Bồ Tát…: 1/ Văn Thù Sư lỵ. 2/ Quan Thế âm…)"`.
- Battle shouts with mid-word ellipses:
  `9786045633946 s17 Text/18.html #135 — "…Sát Thát! S…át Th.. át!… Dườn…"`.
- Footnote marker attached to a word:
  `9786326186253 s4 Text/section_4.html #103 — "… giữa đêm mồng chín tháng mười năm ngoái(2)…"`.
- Near-empty marker blocks: `9786326186253 s1 Text/section_11.html #17 — "• …"`.

## Audiobook characterization (Đêm hội Long Trì)

Observed (`audiobook_tracks.csv`, `audiobook_report.txt`): 7 MP3 tracks
(`dem-hoi-1.mp3`…`dem-hoi-7.mp3`), MP3, 44.1 kHz, stereo, 96 kb/s, total
16,446.6 s (≈ 4 h 34 m). Tags are near-absent (genre=Blues on all tracks,
encoded_by=Lavf52.13.0 on tracks 2–7, no title/author/track tags), so
track identity rests on content, not metadata.

Track-to-section correspondence is a manual judgement, established by
listening to each bronze track and matching the heard opening and ending
against EPUB blocks (listener: the repository owner; the heard openings
and endings are recorded in the table below):

The resulting mapping (recorded in `TRACK_SECTION_CORRESPONDENCE` in
`scripts/inspect_audiobook.py`): track 1 narrates s1 + s2 + s3. Within
track 1, listening identified the biographical content (s1, "Nhà văn
NGUYỄN HUY TƯỞNG (1912 – 1960)… Quê quán: Dục Tú, Đông Anh, Hà Nội",
`s1 Text/section_11.html #1–#3`), then the heading "LỜI NÓI ĐẦU" spoken
aloud followed by "Năm 1942, khi tiểu thuyết Đêm hội Long Trì được đăng
tải…" (`s2 Text/section_2.html #0–#1`), before section I (s3). Tracks 2–7
narrate s4–s9 one-to-one. Every heard ending matches the final block of
the mapped section. All 9 narratable spine documents are covered; s0 and
s10 contain no extracted text and require no text–audio mapping.

Observed at the coarsest useful level:

- Insertion: track 1 opens with a narrator announcement ("Tác phẩm Đêm
  hội long trì, tiểu thuyết…") that has no counterpart in the EPUB.
- Heading verbalization: tracks 2–7 open with the section heading spoken
  in words ("Hai"…"Bảy" for the EPUB's numeral headings II–VII) before
  the section text — a normal reading of the heading, not inserted
  content.
- Omissions/repetitions: no section-level mismatch identified; differences
  within sections were not assessed. The coarse characters-per-second
  check is consistent (10.8–11.7, median 11.3 chars/s per track,
  `audiobook_report.txt`) — descriptive only, not evidence of
  correspondence.
- Limits: no sentence alignment, no ASR; finer insert/omit/repeat
  detection inside sections is deferred to the synchronization work (#12).
